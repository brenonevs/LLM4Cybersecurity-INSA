# Diretrizes e Regras do Usuário

1. **Ambiente e Perfil do Usuário:**
   - O usuário está utilizando um computador **Mac (macOS)** novo e ainda não domina os comandos e atalhos do sistema.
   - Sempre fornecer instruções passo a passo, claras, didáticas e específicas para Mac (atalhos com `Cmd`, caminhos de macOS, comandos de terminal `zsh`).

2. **Execução de Comandos:**
   - NUNCA executar comandos de terminal que instalem pacotes, criem ambientes, executem scripts python ou alterem o sistema por iniciativa própria.
   - Os ÚNICOS comandos permitidos no terminal pelo assistente são estritamente de visualização, inspeção e navegação (ex: `ls`, `cat`, etc., quando estritamente necessários).
   - Qualquer comando que execute scripts ou modifique o ambiente só pode ser rodado se o usuário solicitar expressamente.

3. **Subordinação Estrita às Instruções do Usuário:**
   - Fazer estritamente e somente o que o usuário mandar.
   - Orientar, explicar e analisar os arquivos detalhadamente, deixando a execução e decisões práticas de execução para o usuário.
